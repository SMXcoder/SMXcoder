# Setup (SMXcoder)
1. Create a public repo named exactly `SMXcoder`, push everything in this folder to `main`.
2. Repo Settings > Actions > General > Workflow permissions: allow read and write.
3. Actions tab > "Update profile art" > Run workflow (refreshes the heatmap daily after that).
Edit `config.json` for card text, banner text/font, then `pip install -r scripts/requirements.txt && python scripts/build_all.py`.
